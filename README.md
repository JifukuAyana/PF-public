# ユーザー管理・紹介Webアプリケーション

Java・Spring Bootで作成した、ユーザー管理・ユーザー紹介・問い合わせ管理を行うWebアプリケーションです。

管理画面では、管理者と一般ユーザーで利用できる機能を分け、アカウント管理やプロフィール編集、いいね数の集計、問い合わせ管理を行えます。

また、管理画面とは別のURLにユーザー紹介サイトを用意しています。プロフィールの閲覧やユーザーへのいいね、月別の人気ユーザーランキングの確認、問い合わせの送信ができます。

## 主な機能

### 管理者向け機能

- ユーザーの新規登録・一覧表示・編集・削除
- ユーザーのアクセスステータス切り替え
- 削除済みアカウントの一覧表示・復元・完全削除
- 問い合わせカテゴリーの追加・編集・削除
- カテゴリー別の問い合わせ一覧確認
- 問い合わせの一覧・詳細・対応ステータスの確認
- 月間・年間ランキングの表示

### 一般ユーザー向け機能

- 自分の月間・年間のいいね数の確認
- カテゴリーを選択して問い合わせを送信
- アカウント設定・プロフィールの変更

### ユーザー紹介サイト

管理画面とは別のURLから、ユーザーを紹介する画面を閲覧できます。

- ユーザーの画像・名前などをカード形式で一覧表示
- 詳細画面でプロフィールや自己紹介を表示
- 各ユーザーへのいいね・いいね数の表示
- 月を選択して人気ユーザーランキングを表示
- カテゴリー・メールアドレス・件名・本文を入力して問い合わせを送信
- ログイン画面へのリンクを設置

### その他の機能

- ログイン・ログアウト
- プロフィール画像の登録・変更
- ユーザー名・メールアドレス・パスワードの変更

## 実装上のポイント

### 権限に応じた機能の分離

管理者にはユーザー管理や問い合わせ管理の機能を、
一般ユーザーには自身の情報確認や問い合わせ送信の機能を提供しています。
利用者の役割に応じて、表示するメニューや利用できる機能を分けています。

### 管理画面とユーザー紹介サイトの分離

アカウントや問い合わせを管理する画面と、
ユーザーのプロフィールを閲覧する紹介サイトを別のURLに分けています。

紹介サイトではカード形式の一覧と詳細画面を用意し、
ユーザーの情報を確認できる構成にしています。

### アカウントの削除と復元

削除済みアカウントを別の一覧で管理し、
復元と完全削除を選択できる構成にしています。

### いいねの集計・表示

管理者画面では月間・年間ランキングを、
一般ユーザー画面では自身の月間・年間のいいね数を表示します。

ユーザー紹介サイトでは、各ユーザーのいいね数に加えて、
月を選択して人気ユーザーランキングを確認できます。

### 問い合わせの分類

問い合わせをカテゴリー別に整理し、
管理者が内容や対応ステータスを確認できる構成にしています。

一般ユーザー向け画面とユーザー紹介サイトに、
問い合わせを送信するフォームを用意しています。

## ディレクトリ構成

| パス | 内容 |
|---|---|
| src/main/java | アプリケーションのJavaコード |
| src/main/resources | 画面テンプレート・静的ファイル・設定 |
| src/test | テストコード |
| upload-dir/profile-images | プロフィール画像の保存先 |
| .mvn/wrapper | Maven Wrapperの設定 |
| pom.xml | 依存ライブラリ・ビルド設定 |

## 実行時の設定

データベース接続情報とメール認証情報は、環境変数から読み込みます。
実行環境で次の変数の設定が必要です。

| 環境変数 | 内容 |
|---|---|
| DB_URL | MySQLの接続URL |
| DB_USERNAME | データベースのユーザー名 |
| DB_PASSWORD | データベースのパスワード |
| MAIL_USERNAME | メール送信用アカウント |
| MAIL_PASSWORD | メール送信用の認証情報 |
